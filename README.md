An interactive **3D Nonlinear Dynamical Systems, Strange Attractor & Chaos Theory Astrolabe** powered by a native **C++17 RK4 & Benettin Lyapunov Spectrum Engine (chaos_engine.cpp)**, bridged with **Python (ctypes)** and **Three.js WebGL**.

Live Interactive Web App: **https://rksupreme5-ux.github.io/empyrean-chaos-cpp/**

## Key Features
- **Native C++17 Nonlinear Dynamics Kernel (chaos_engine.cpp):** Automatically compiles on startup via g++ -O3 -std=c++17 to compute maximal Lyapunov exponents, phase-space dissipation rates, and Kaplan-Yorke fractal dimensions (D_KY).
- **6 Iconic Chaotic Attractors:** Aizawa Celestial Torus, Lorenz Twin Butterfly, Thomas Crystal Lattice, Halvorsen Triskelion, Dadras Hyper-Scroll, and Chen Dual Resonance.
- **Live Butterfly Effect Divergence Experiment:** Launches twin trajectories separated by 10^-4 with a real-time 3D divergence vector bridge and Poincare section return map.
- **3 Empyrean Sanctuary Realms:** Dawn Gold, Astral Indigo, and Marble Pantheon with 3D rotating armillary astrolabe gimbal rings.
